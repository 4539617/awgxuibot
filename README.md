# 🚀 AWGXUIBOT

---

## 📦 Быстрая установка

```bash
git clone https://github.com/4539617/awgxuibot.git /opt/awgxuibot
cd /opt/awgxuibot
bash install.sh
```

---

## 📋 Интерактивное меню

После запуска установщика появится меню управления:

```
========================================
   AWGXUI install:
========================================
1) Показать статус системы
2) 3X-UI
3) CASCADE WEB UI
4) AWG
5) XUIBOT
6) AWGBOT
7) Обслуживание
0) Выход
========================================
```

Каждый пункт открывает подменю:

**3X-UI**
```
1) Установка 3x-ui Panel v2.9.4
2) Установка 3x-ui Panel v3.x.x
3) Удаление 3x-ui Panel
0) Назад
```

**CASCADE WEB UI**
```
1) Установка Cascade Web UI
2) Логи Cascade
3) Пересборка Cascade
4) Удаление Cascade
0) Назад
```

**AWG**
```
1) Установка AWG
2) Удаление AWG
3) Сформировать конфигурацию AWG v1
4) Сформировать конфигурацию AWG v2
5) Запустить AWG v1
6) Запустить AWG v2
7) Остановить AWG v1
8) Остановить AWG v2
0) Назад
```

**XUIBOT**
```
1) Установка XUIBOT
2) Логи XUIBOT
3) Пересборка XUIBOT
4) Удаление XUIBOT
0) Назад
```

**AWGBOT**
```
1) Установка AWGBOT
2) Логи AWGBOT
3) Пересборка AWGBOT
4) Удаление AWGBOT
0) Назад
```

**Обслуживание**
```
1) Анализ диска и памяти
2) Безопасная очистка (автоматическая)
3) Настройка обратного каскада 3x-ui
99) Удалить ВСЁ (AWG + Боты + 3x-ui + Cascade)
0) Назад
```
